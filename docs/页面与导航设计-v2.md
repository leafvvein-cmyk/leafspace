# 页面与导航设计 v2

日期：2026-09-08 · 配套：[产品方案](产品设计方案-v2.md) · [接口设计](接口与数据设计-v2.md)。以下均为待开发规范。

## 1. 页面关系与路由规则

两端使用相同页面标识与参数。Web 使用浏览器路径，服务器将非 API 页面回退到应用入口；手机使用本地路由栈。`/entries/:id` 是只读详情，`/entries/:id/edit` 是编辑页，路由命名不混用。

| 分组 | 路由 | 页面 | 主要入口 / 返回目标 |
| --- | --- | --- | --- |
| 账户 | `/login` | 登录 | 未登录进入；成功回到安全的站内 returnTo 或今天 |
| 账户 | `/register` | 注册 | 登录页下方；成功进入恢复码设置 |
| 账户 | `/recover` | 恢复账号密码 | 登录页“忘记密码”；成功回登录 |
| 账户 | `/onboarding/recovery` | 保存恢复码 | 首次注册；保存提示确认后进入今天 |
| 账户 | `/lock` | 本地解锁页 | 自动锁定；成功恢复原页面 |
| 写作 | `/today?date=YYYY-MM-DD` | 今天/指定一天 | 主导航；默认今天，可前后切天 |
| 写作 | `/entries/new?kind=daily&date=YYYY-MM-DD` | 新建每日稿 | 今天/新建菜单；有同日记录则转到原记录 |
| 写作 | `/entries/new?kind=moment&date=YYYY-MM-DD` | 新建随记稿 | 全局新建、今天随记入口 |
| 写作 | `/entries/:id` | 日记阅读 | 时间线、搜索、日历、标签 |
| 写作 | `/entries/:id/edit` | 日记编辑 | 阅读页“编辑”；返回阅读或来源列表 |
| 查阅 | `/timeline` | 时间线 | 主导航；kind、mood、tagId、from、to 筛选 |
| 查阅 | `/calendar?month=YYYY-MM` | 月历 | 主导航；点击日期显示当天条目 |
| 查阅 | `/search` | 搜索 | 桌面导航、手机列表顶部；q 只保存在内存，不写 URL/history |
| 查阅 | `/tags`、`/tags/:tagId` | 标签与标签下日记 | 桌面导航、手机“我的” |
| 待办 | `/tasks` | 待办列表 | 电脑侧栏、手机底栏；今天/计划/已完成筛选 |
| 待办 | `/tasks/new`、`/tasks/:id` | 新建/编辑待办 | 待办列表、提醒通知；返回保留筛选和滚动位置 |
| 待办 | `/tasks/:id/actions` | 待办动作 | 待办详情；选择已登记动作，不直接输入任意协议 |
| 密码本 | `/vault` | 密码本锁屏/列表 | 电脑侧栏、手机“我的”；未解锁时不渲染摘要 |
| 密码本 | `/vault/items/new`、`/vault/items/:id` | 新建/查看密码条目 | 保险库已解锁后进入；离开或锁定立即清除可见明文 |
| 管理 | `/trash` | 回收站 | 桌面侧栏下方、手机“我的” |
| 管理 | `/sync` | 同步中心 | 任意同步状态徽标、设置 |
| 管理 | `/conflicts/:conflictId` | 冲突比较 | 同步中心；conflictId 属于本机工作副本 |
| 设置 | `/settings` | 设置/我的总览 | 桌面底部、手机底栏 |
| 设置 | `/settings/account` | 账号安全 | 改密、恢复码、退出、注销 |
| 设置 | `/settings/devices` | 登录设备 | 设备列表、远程退出 |
| 设置 | `/settings/appearance` | 外观与阅读 | 主题、字体、字号、写作宽度 |
| 设置 | `/settings/privacy` | 日记锁与隐私 | 锁定时机、本地存储说明 |
| 设置 | `/settings/reminders` | 写作提醒 | 当前设备时间、权限、测试提醒 |
| 设置 | `/settings/data` | 导出与存储 | 云端导出、本地未同步稿导出、缓存信息 |
| 设置 | `/settings/about` | 关于与安装 | 版本、buildId、安装引导、更新状态 |
| 文档 | `/legal/privacy`、`/legal/terms` | 隐私说明与用户协议 | 登录页与设置，未登录也可访问 |

路由状态规则：列表滚动、筛选、月份和来源保存在页面会话状态；禁止把正文、密码、恢复码、访问令牌放在 URL。应用内可控制的导航先落盘再离开；浏览器后退、手机手势能拦截时同样处理。关闭标签、系统终止等无法可靠拦截的退出，只保证最近成功落盘内容，因此写作期间持续保存，不能依赖关闭事件。找不到记录显示说明和返回入口。深链接只接受白名单页面和当前账号可访问的 ID。

## 2. 电脑布局

桌面主导航：今天、待办、时间线、日历、搜索、标签。密码本、回收站、同步状态、设置位于侧栏底部，顶部有品牌和“写日记”。

普通宽屏参考结构：

```text
┌──────────────┬────────────────────────────────────────────┐
│ 日记         │ 今天 · 9月8日          搜索  写随记  头像   │
│ 写日记       ├──────────────────────────────┬─────────────┤
│ 今天         │ 今天的日记                   │ 今日随记    │
│ 时间线       │ 心情 / 标签                  │ 09:10 …     │
│ 日历         │ 标题                         │ 18:30 …     │
│ 搜索         │                              │             │
│ 标签         │ 正文书写区                   │             │
│              │                              │             │
│ 回收站       │ 已保存在此设备 · 等待同步     │             │
│ 同步 / 设置  └──────────────────────────────┴─────────────┤
└──────────────┴────────────────────────────────────────────┘
```

今天是编辑优先双栏；时间线是日记列表+阅读详情。不要把日历、统计、提示卡同时塞到今天页正文上方。统计只在设置总览提供累计天数和篇数，避免占据写作空间。

大屏使用约 216px 侧栏；随记栏约 260px；时间线列表约 320px；正文内部居中且最大约 760px。空间不够时先收起辅助栏。专注模式隐藏侧栏、随记栏和非必要元数据，Esc 可退出。

## 3. 手机布局

底部固定四项：今天、待办、时间线、我的。每项同时有图标和文字。日历、标签、密码本、回收站、数据导出、同步中心位于“我的”；搜索入口在今天和时间线右上角，不增加第五个底栏入口。

```text
┌─────────────────────────┐
│ 今天 · 9月8日     搜索 ＋ │
│ 轻松 · 晴朗的一天        │
│ ┌─────────────────────┐ │
│ │ 今天的日记          │ │
│ │ 正文摘要……          │ │
│ │ 继续写              │ │
│ └─────────────────────┘ │
│ 随记              新建  │
│ 09:10 早晨的小事……      │
│ 18:30 回家的路上……      │
├─────────────────────────┤
│ 今天  时间线  日历  我的 │
└─────────────────────────┘
```

手机今天默认显示摘要，点击“继续写”进入全屏编辑。编辑时底栏隐藏，顶部是返回、日期、更多，键盘上方为可横向滚动的格式工具栏。保存状态显示在标题下方，避免依赖底部才看得到。

新增“＋”打开操作面板：写当天日记、记一条随记。已有 daily 时第一个选项显示“继续当天日记”。随记卡片不要以滑动删除作为唯一入口。

适配要求：触控目标至少 44px，主要按钮约 48px；正文允许系统字体放大；适配 `safe-area-inset-*`；键盘出现后不遮挡光标、底部工具和错误提示。手机相册、拍照、分享使用原生能力适配。

## 4. 断点与通用组件

| 宽度 | 导航 | 内容 |
| --- | --- | --- |
| ≥ 1280px | 完整左侧栏 | 今天正文+随记，时间线列表+详情 |
| 768–1279px | 可折叠侧栏/抽屉 | 主内容优先，随记折叠到正文下方 |
| < 768px | 手机底栏 | 单列卡片，阅读/编辑独立页面 |

复用组件：`AppShell`、`Navigation`、`DiaryCard`、`EditorToolbar`、`MoodPicker`、`TagPicker`、`SaveStatus`、`OfflineBanner`、`ConfirmDialog`、`EmptyState`、`InlineError`、`Toast`。这些先做为小型 JS 模块，职责独立，不要求 UI 框架。

每个组件有 loading / empty / ready / error 等真正需要的状态。表单用显式 label，图标按钮有名称，错误信息关联控件。键盘焦点可见，弹窗打开时焦点进入弹窗，关闭回到触发按钮。

配色以产品方案为基线；正文/按钮文字目标至少 4.5:1 对比，大号文字目标 3:1。实际颜色需在样页验收测量，尤其浅色辅助文字和深色模式。

## 5. 逐页交互规格

### P01 登录、注册、找回和首次设置

电脑登录使用左侧一句品牌文案、右侧约 400px 表单；手机单列，首屏可见账号和密码，不依赖装饰图。

- 登录：账号、密码、显示密码开关、登录按钮、注册/忘记密码链接。
- 注册：账号、密码、确认密码。账号 3–32 位 ASCII 字母/数字及 `._-`，首位字母或数字，不区分大小写；新系统密码 12–128 个 Unicode 码点，允许粘贴与密码管理器，无大小写符号硬凑规则，具体编码边界见接口文档。
- 提交中禁止重复发送，输入错误展示在字段旁；错误账号与错误密码统一提示“账号或密码错误”。达到频率限制显示等待时间。
- 恢复码：注册后的专页显示一次，可复制/下载；说明其可重置密码，确认已保存后继续。跳过时在安全页持续给温和提醒。
- 找回：账号、恢复码、新密码、确认新密码。成功后退出所有设备并回登录，新登录后重新生成恢复码；不会凭“账号名称”直接重置。
- 首次登录无内容时，展示“写下今天的第一句话”，不灌入冒充用户的示例日记。

使用 `GET /auth/csrf`、Web/Native 的 register/login/refresh、`GET /me`、`POST /security/recovery-code`、`POST /auth/password-reset`。表单重复确认字段在客户端校验，不作为存储字段。

### P02 今天

顶部日期切换；主区域是当天 daily，辅助区域是随记列表。没有每日记录时显示“从一句话开始”与编辑入口，首次真正输入才创建草稿。

已存在每日时直接继续原篇。点过去的日期进入那天，不偷偷改为当前日期；跨午夜编辑保持原日期，显示“已是新的一天，可以另写今天”。

心情可取消，标签可输入新名称；暂未同步的新标签显示在本地，上传时用请求名称映射到服务器 tag ID。页面使用 `GET /entries?date=...`，写入统一走 mutation 服务。

### P03 编辑器与阅读页

支持标题、日期、心情、标签、正文；正文允许段落、标题、粗体、斜体、下划线、无序/有序列表、待办、引用、分隔线和图片。只允许白名单节点/属性，粘贴外部内容时清除脚本、事件属性和危险链接。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 输入 | 正文宽度受控，工具栏固定在内容区顶部 | 全屏，键盘上方工具栏 |
| 常用格式 | Ctrl/Cmd+B、I、Z；Ctrl/Cmd+S 执行本地落盘并触发同步 | 工具栏按钮，选区不因点击丢失 |
| 插图 | 文件选择或拖入 | 相册/拍照选择，取消选择不报错 |
| 阅读 | 清晰排版，可进入专注模式 | 全屏阅读，顶部编辑入口 |
| 删除 | 更多菜单→移到回收站 | 同名菜单项，避免误触 |
| 返回 | 应用内切页等待落盘；失败保留编辑器与恢复选项 | 处理可拦截的顶部/系统返回与手势；系统强关只保证已成功落盘内容 |

状态文案：正在保存 → 已保存在此设备 → 等待同步/同步中 → 已同步；出现冲突则是“需要处理版本”，不是泛化“保存失败”。图片队列单独显示“图片待上传 n 张”。

正文撤销/重做仅控制本地编辑历史，不能撤销已经发生的远程永久删除。全空未提交草稿不计篇数；已保存的记录清空正文时需保留至少标题/正文/附件之一，否则显示空内容校验。

阅读页有编辑、导出、移到回收站；图片大图查看只使用本账号短期读链接或本地缓存。用户选取的原图不把 Base64 塞入日记正文 JSON。

### P04 时间线

按日期分组，卡片显示标题、两行摘要、时间、类型、心情、标签、第一张缩略图和同步状态。首屏 50 项分页，最多一次请求 100 项，长列表采用按需渲染。

类型筛选“全部/每日/随记”，可叠加日期、标签和心情；清空筛选入口一直可见。手机点击打开详情，电脑打开旁边预览；返回恢复滚动和选中记录。

批量选择提供移到回收站；只选择明确展示的条目，不能把当前页选择悄悄扩展为所有匹配结果。筛选无结果与完全没写过使用不同空状态。

使用 `GET /entries`，删除使用 `POST /sync/mutations` 的 `trash` 操作。

### P05 月历

顶部年月与前后月按钮，今日有轮廓，每天用计数/标记显示是否有 daily 和随记。文字与形状同时表达状态。

点击日期打开当天条目；空日期显示“补写这一天”。电脑日历旁显示当天列表，手机底部面板展示列表后进入详情；月份切换取消过期请求，避免慢响应把新月份覆盖。

使用 `GET /calendar?month=YYYY-MM`。离线时由本地 entries 聚合并标注“仅此设备内容”。

### P06 搜索与标签

搜索框显式 label，支持清空和最近本次查询；第一版不保存搜索词历史到服务端。输入约 300ms 防抖，限制关键词长度 100 字符。请求序号/取消机制保证旧结果不覆盖新结果。

结果显示纯文本命中摘要，高亮使用安全文本节点；可以叠加日期区间、心情、类型和标签。显示“搜索全部已同步日记”或“仅搜索此设备已下载日记”。

标签管理显示名称、篇数；支持新增、改名、删除标签、与已有同名标签合并。删除标签不删除日记，需要说明受影响的篇数；离线可在日记上添加标签名称，批量管理要求在线。

搜索使用 `GET /entries?q=...`；标签使用 `GET/POST /tags`、`PATCH/DELETE /tags/:id`、`POST /tags/:id/merge`。

### P07 回收站

列表显示原标题、删除时间、剩余保留天数。点条目进入只读预览，可恢复；彻底删除按钮包含名称和不可恢复说明，批量时列出数量。

恢复 daily 时若当天已有 daily：显示“此日期已有日记”，提供更换日期或恢复为随记；原文始终留在回收站直到恢复成功。永久删除要求在线；离线只排队软删除，不能宣称云端已永久清除。

使用 `GET /entries?state=trash`、mutation `restore/trash`、`POST /entries/:id/purge`。永久批量删除一次最多 20 篇，绑定明确选中项再次验证，调用 `POST /entries/purge-batch`；任何版本冲突则整批不删除，刷新后重新确认。到期依据服务器 `purgeAfter`，不按设备时钟直接删除。

### P08 同步中心与冲突

总览显示待上传记录/图片数、失败数、最近成功时间，提供重试和逐项查看。未登录或会话失效显示重新登录，429 显示稍后自动重试；冲突不进行无限重试。

冲突页电脑左右比较，手机在“本机/云端”标签间切换，可看差异概述和完整正文。操作包括：保留云端、把本机另存为随记、手工合并；放弃本机前明确确认。合并再次遇到更新则刷新云端版本并保留用户合并草稿。

远端删除的冲突明确写“这篇日记已在其他设备删除”。永久删除后的稿只能另存新 ID，不复活原记录。内容只在当前账号空间比较。

主要使用 `POST /sync/mutations`、`GET /sync/changes`；队列、错误原因、conflictId 保存在本地库。

### P09 设置总览与外观

账号摘要只显示昵称/账号、累计记录天数和篇数。入口依次为账号安全、登录设备、外观、日记锁、提醒、数据导出与存储、同步中心、关于。

外观：浅色/深色/跟随系统；正文字体；字号 16–24px；电脑书写宽度。立即本地预览，联网保存用户偏好；系统通知权限、锁设置和缓存开关不跟着云端偏好强制开启其他设备。

### P10 设备与安全

设备列表：名称、web/android/ios 平台、最近活动、创建时间、本设备标识。确认远程退出时显示目标名称；退出全部其他设备保留本设备，改密则撤销所有设备并要求重新登录。

敏感操作先验证当前密码，获得 5 分钟、绑定具体操作的 reauth token；展示原因，不把密码放在常规设备请求中。恢复码可重新生成，新码使旧码失效。

使用 `GET /sessions`、`DELETE /sessions/:id`、`POST /sessions/revoke-others`、`POST /auth/reauth`、`POST /security/password`。

### P11 日记锁与提醒

日记锁设置设备级。App 默认建议回到后台即锁定，可选短宽限；任务切换预览遮盖正文。网页明确为界面锁，提供手动锁定和空闲锁定，在线重新验证或已配置本机 PIN 解锁；未配置离线解锁方式时不能离线绕过锁。

提醒为设备级：开关、每天时间、星期选择、时区策略、测试提醒。先展示说明再调用系统权限；拒绝后展示到系统设置的说明，不反复请求。默认通知正文为“给今天留一句话”，不显示日记标题/正文。

手机本地通知安排在系统中；电脑第一版仅应用开启时提醒。如果用户需要关闭电脑应用后仍提醒，作为独立 Web Push 任务，需要服务端调度和订阅管理。

### P12 导出、存储、注销与关于

导出可选日期范围、类型和是否含图片。Markdown/JSON+图片 ZIP 在服务端后台生成，页面显示排队/处理中/可下载/失败；有效期 24 小时，到期重新生成。单篇电脑 PDF 使用打印样式；手机通过打印/分享适配导出。

有未同步稿时明确云端导出不包含它们，先同步或单独导出本机稿。完整备份 JSON 含 schemaVersion 和附件索引；恢复演练属于运维验收，面向用户的任意 ZIP 导入器不在本次默认范围。

存储页把“可重新下载的缓存”和“未同步内容”分开计数；只清理前者。网页提示用户清除浏览器站点数据会影响本地未同步稿。注销页引导先导出，验证密码并确认后立即停用账户，显示清理回执。

关于显示 Web buildId、API 版本、App 版本和本地 schemaVersion；有新 Web 版本时点“保存并更新”，先完成本地事务再激活新 SW。首次安装、更新中、更新失败都有明确文案。

### P13 待办与动作

待办列表默认分为逾期、今天、之后和无日期，提供未完成/已完成切换、优先级与关键词筛选。新建页包含标题、备注、截止时间、时区、重复规则、提醒、子项和可选关联日记；完成重复任务时生成下一次实例，网络重试不得重复生成。

动作区显示动作名称、目标 App 和执行说明。点击“打开企业微信”或其他外部 App 前再次展示将要打开的目标；成功唤起只记录动作尝试，不自动完成待办。未安装、浏览器不允许、系统拒绝或参数失效时显示失败原因和备用 HTTPS/复制操作。后台提醒只能把用户带回待办详情，由用户继续点击动作，不静默拉起第三方 App。

### P14 密码本

首次进入先创建保险库密码并说明它与账号登录密码不同；创建成功后以不可跳过的弹窗一次性显示恢复密钥，必须确认已另存后关闭。锁定页在配置存在恢复包装时提供“使用恢复密钥”，验证后设置新密码并换发新恢复密钥；解锁页还可主动换发，使旧密钥失效。列表默认只显示用户自定义名称和类型，不显示密码或备注摘要。搜索仅在本机解锁后的已解密内存中进行，不上传搜索词或明文索引。

新建条目先选择“App 账号”或“网站账号”，再填写服务名称、登录账号、密码、网站登录地址或 App 标识，以及可选备注和收藏。动态验证码折叠区可保存 Base32 TOTP 密钥并选择 6/8 位、30/60 秒周期；账号卡明确点击后才在本机生成当前验证码，并在周期结束或锁定时遮挡。同一服务允许多条记录，名称、分组和收藏均在解锁后由本机解密和计算。当前不承诺浏览器/系统级自动填充、短信验证码、二维码扫描或服务商专有令牌。

密码默认遮挡，查看、复制账号和复制密码是独立操作；网站地址可在确认后打开，App 标识只用于后续受控唤起，不拼接任意协议。页面失焦、应用进后台、达到自动锁定时间或会话切换时，清除内存中的明文和复制状态。导出保险库必须单独再次验证、使用加密格式并明确说明恢复方法；普通日记导出永不包含密码本。

## 6. 关键状态统一规范

| 状态 | 页面表现 | 操作 |
| --- | --- | --- |
| 加载 | 列表骨架；编辑已有本地内容立即展示 | 仅阻止依赖未加载数据的操作 |
| 无数据 | 一句说明 + 一个主动作 | 新建/清除筛选/返回今天 |
| 离线 | 顶部轻提示 + 本地保存状态 | 可编辑；云端管理说明需联网 |
| 会话过期 | 保留已落盘稿，出现登录入口 | 登录同账号恢复队列 |
| 保存失败 | 原文保留、醒目文字提示 | 重试/复制/导出本机稿 |
| 同步冲突 | 徽标与同步中心入口 | 查看、另存或手工合并 |
| 图片失败 | 占位、原因、进度 | 重试或移除此图 |
| 权限拒绝 | 当前功能旁给说明 | 手动设置或使用可用替代方式 |
| 服务维护 | 可离线查阅和编辑 | 稍后重试，避免持续弹窗 |

## 7. 视觉与交互交付清单

每个阶段至少展示电脑 1440px、窄窗口 1024px、手机 390px 和最小 360px 四种宽度；关键页追加深色和字体放大样例。截图或视觉稿应使用虚构内容，明确为示例。

M0 首先交付今天、编辑、登录三页设计样例；风格稳定后复用组件扩展时间线、日历、搜索和设置。每页验收包含视觉层级、焦点、触摸范围、错误和空状态。样式完成不能代替功能测试，单次网页构建也不能代替手机 App 真机检查。

产品文案统一使用“日记、每日、随记、已保存在此设备、已同步、回收站”。开发文档里的 mutation、cursor、revision 不直接暴露给普通用户，只在诊断页中使用。
