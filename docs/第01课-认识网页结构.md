# 第 01 课：HTML 基础规则与网页结构

## 1. 本课完成后要会什么

学完这一课，你应该能够：

1. 解释 HTML、CSS、JavaScript 各自负责什么。
2. 看懂一个完整 HTML 文档的基本结构。
3. 正确使用开始标签、结束标签、属性和注释。
4. 理解标签嵌套、缩进、标题层级和 `id` 唯一性等规则。
5. 使用语义标签搭建日记网站的静态页面。
6. 使用 `label`、`input`、`textarea` 和 `button` 创建基础表单。

本课暂时不处理颜色、布局和按钮点击效果。页面不好看是正常的，因为这些分别属于 CSS 和 JavaScript。

## 2. HTML、CSS、JavaScript 的分工

可以把网页想象成一间房子：

| 技术 | 负责内容 | 房屋比喻 |
| --- | --- | --- |
| HTML | 内容和结构 | 墙、门、房间 |
| CSS | 颜色和布局 | 装修、家具、灯光 |
| JavaScript | 行为和数据 | 开关、门锁、自动设备 |

例如，`<button>保存日记</button>` 用 HTML 创建按钮。CSS 可以让按钮变成棕色，JavaScript 可以让点击按钮后保存日记。

## 3. HTML 和标签

HTML 全称是 HyperText Markup Language，中文叫“超文本标记语言”。它使用标签标记内容的含义：

```html
<h1>我的日记</h1>
<p>记录今天发生的事情。</p>
```

- `<h1>` 表示一级标题。
- `<p>` 表示一个文本段落。

### 成对标签

```html
<p>今天是晴天。</p>
```

它包含开始标签 `<p>`、内容和结束标签 `</p>`。结束标签比开始标签多一个 `/`。

### 空元素

有些元素不能包含内容，不需要单独的结束标签：

```html
<input type="text">
<img src="photo.jpg" alt="雨后的街道">
<br>
<hr>
```

常见空元素包括 `input`、`img`、`br`、`hr`、`meta` 和 `link`。不要写成 `<input>内容</input>`。

## 4. 属性

属性为元素提供额外信息，写在开始标签内：

```html
<input id="diary-title" type="text" placeholder="给今天起个标题">
```

- `id="diary-title"`：给元素一个唯一名称。
- `type="text"`：输入普通文本。
- `placeholder`：输入为空时显示提示文字。

属性基本格式是 `属性名="属性值"`。

### 属性使用规则

1. 属性写在开始标签内。
2. 属性名推荐使用小写字母。
3. 属性值推荐始终使用双引号。
4. 多个属性使用空格分隔。
5. 同一个元素不要重复写同名属性。

推荐：

```html
<input type="text" id="title" required>
```

不推荐：

```html
<INPUT TYPE=text id=title id=another-title>
```

## 5. 完整 HTML 文档

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的日记</title>
  </head>
  <body>
    <h1>我的日记</h1>
    <p>记录每一个值得保存的日子。</p>
  </body>
</html>
```

### 每行的用途

- `<!doctype html>`：告诉浏览器使用现代 HTML 标准，必须放在第一行。
- `<html lang="zh-CN">`：整个网页的根元素，主要语言为简体中文。
- `<head>`：保存网页设置，通常不直接显示在正文中。
- `<meta charset="UTF-8">`：使用 UTF-8 编码，防止中文乱码。
- viewport 设置：让页面宽度适应手机屏幕。
- `<title>`：浏览器标签页标题，不是正文大标题。
- `<body>`：用户在页面中看到的内容。

## 6. 标签嵌套

元素可以放在另一个元素里面：

```html
<section>
  <h2>今天的日记</h2>
  <p>今天学习了 HTML。</p>
</section>
```

### 后打开、先关闭

正确：

```html
<p>今天学习了 <strong>HTML</strong>。</p>
```

错误：

```html
<p>今天学习了 <strong>HTML。</p></strong>
```

可以把标签想象成盒子，后放进去的盒子必须先拿出来。

### 缩进规则

推荐每嵌套一层缩进两个空格：

```html
<main>
  <section>
    <h2>编辑日记</h2>
  </section>
</main>
```

缩进通常不改变页面效果，但能帮助人检查结构。

## 7. 常用结构标签

### 标题 `h1` 到 `h6`

```html
<h1>我的日记</h1>
<h2>今天的记录</h2>
<h3>上午</h3>
```

规则：

- 一个页面通常只有一个主要 `h1`。
- `h2` 是 `h1` 下的章节标题，`h3` 是 `h2` 下的小节标题。
- 不要为了改变字体大小随意跳级；字体大小由 CSS 设置。

### 段落 `p`

一段独立文字使用一个 `p`，不要用很多 `<br>` 模拟段落。

### 语义结构

| 标签 | 常见用途 |
| --- | --- |
| `header` | 页面或区域的头部 |
| `nav` | 导航链接区域 |
| `main` | 页面主要内容，每个页面通常只有一个 |
| `aside` | 侧边栏或辅助内容 |
| `section` | 有明确主题的内容区域 |
| `article` | 可独立阅读的一篇内容，例如一篇日记 |
| `footer` | 页面或区域底部 |
| `div` | 没有更合适语义时使用的普通容器 |

优先使用有含义的标签，不要所有区域都只用 `div`。

## 8. `class` 和 `id`

### `class`

`class` 表示分类，可以重复用于多个元素：

```html
<button class="primary-button">保存</button>
<button class="primary-button">新建</button>
```

一个元素可以有多个 class，中间使用空格：

```html
<button class="button danger-button">删除</button>
```

### `id`

`id` 表示页面内唯一身份：

```html
<textarea id="diary-content"></textarea>
```

规则：

- 同一页面不能出现两个相同 `id`。
- 多个元素共享样式时使用 `class`。
- 精确关联或查找某个元素时可以使用 `id`。
- 推荐英文小写加短横线，例如 `diary-title`。

## 9. 表单元素

### `label`

```html
<label for="diary-title">日记标题</label>
<input id="diary-title" type="text">
```

`label` 的 `for` 必须和输入框 `id` 相同。这样点击说明文字时，输入框也会获得焦点。

### `input`

```html
<input
  id="diary-title"
  name="title"
  type="text"
  maxlength="80"
  placeholder="给今天起个标题"
  required
>
```

| 属性 | 作用 |
| --- | --- |
| `type` | 输入类型，如 `text`、`date`、`password` |
| `id` | 页面内唯一名称 |
| `name` | 提交数据时的字段名称 |
| `placeholder` | 空输入框提示文字 |
| `maxlength` | 最多允许输入的字符数 |
| `required` | 表示必填 |
| `value` | 当前或默认值 |
| `autocomplete` | 浏览器自动填充提示 |

`required` 是布尔属性。只要出现就表示启用，不要写 `required="false"`；要关闭它，应删除整个属性。

### `textarea`

```html
<label for="diary-content">正文</label>
<textarea
  id="diary-content"
  name="content"
  rows="12"
  placeholder="今天发生了什么？"
></textarea>
```

`textarea` 用于多行文字。它的默认内容写在标签中间：

```html
<textarea>这是默认内容</textarea>
```

### `button`

```html
<button type="button">保存日记</button>
```

- `type="button"`：普通按钮，由 JavaScript 控制。
- `type="submit"`：提交所在表单。
- `type="reset"`：重置表单，应谨慎使用，避免误删内容。

建议始终明确写 `type`。表单里的按钮没有类型时，浏览器通常会把它当成提交按钮。

## 10. 列表

```html
<ul>
  <li>8 月 19 日：开始学习 HTML</li>
  <li>8 月 18 日：整理学习计划</li>
</ul>
```

- `ul`：无序列表。
- `ol`：有顺序的列表。
- `li`：一条列表项目，只应直接放在 `ul` 或 `ol` 中。

## 11. 注释

```html
<!-- 日记编辑区域 -->
<section class="editor">
  <h2>编辑日记</h2>
</section>
```

注释不会显示在页面上。注释应该解释“为什么”，不要写入密码、密钥或私人数据。

## 12. 特殊字符

| 想显示 | HTML 写法 |
| --- | --- |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| 不换行空格 | `&nbsp;` |

要在页面中显示 `<h1>`，可以写：

```html
<p>一级标题标签写作 &lt;h1&gt;。</p>
```

## 13. 文件和命名规则

- 首页文件使用 `index.html`。
- 文件名使用英文小写。
- 多个单词使用短横线，如 `diary-detail.html`。
- 不使用空格、中文标点或特殊符号作为代码文件名。
- `class` 和 `id` 使用英文小写加短横线。
- 名称描述用途，不描述临时颜色，例如推荐 `save-button`，不推荐 `red-button`。

## 14. 日记首页完整示例

先阅读，再按照下一节的顺序亲手输入：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的日记</title>
  </head>
  <body>
    <header class="site-header">
      <h1>我的日记</h1>
      <p>记录每一个值得保存的日子。</p>
    </header>

    <main class="diary-layout">
      <aside class="diary-sidebar">
        <button type="button" class="new-diary-button">写新日记</button>

        <section aria-labelledby="diary-list-title">
          <h2 id="diary-list-title">以前的日记</h2>
          <ul class="diary-list">
            <li>今天还没有保存任何日记</li>
          </ul>
        </section>
      </aside>

      <section class="diary-editor" aria-labelledby="editor-title">
        <h2 id="editor-title">今天的日记</h2>
        <p>2026 年 8 月 19 日</p>

        <form class="diary-form">
          <label for="diary-title">标题</label>
          <input
            id="diary-title"
            name="title"
            type="text"
            maxlength="80"
            placeholder="给今天起个标题"
            required
          >

          <label for="diary-content">正文</label>
          <textarea
            id="diary-content"
            name="content"
            rows="12"
            placeholder="今天发生了什么？"
            required
          ></textarea>

          <div class="form-actions">
            <button type="submit">保存日记</button>
            <button type="button">删除</button>
          </div>
        </form>

        <p class="save-status">今天还没有保存</p>
      </section>
    </main>
  </body>
</html>
```

## 15. 正确的练习顺序

1. 写 `doctype`、`html`、`head` 和 `body`。
2. 在 `body` 中添加 `header`。
3. 添加 `main`，再放入 `aside` 和 `section`。
4. 在侧栏添加按钮和列表。
5. 在编辑区添加标题、日期和表单。
6. 检查缩进、结束标签和重复 `id`。

每完成一步都可以用浏览器打开 `index.html`。确认页面仍能显示后再继续。

## 16. 常见错误

### 忘记关闭标签

```html
<!-- 错误 -->
<p>今天学习 HTML

<!-- 正确 -->
<p>今天学习 HTML。</p>
```

### 标签交叉

```html
<!-- 错误 -->
<p><strong>重要内容</p></strong>

<!-- 正确 -->
<p><strong>重要内容</strong></p>
```

### 重复使用 id

```html
<!-- 错误 -->
<input id="title">
<textarea id="title"></textarea>

<!-- 正确 -->
<input id="diary-title">
<textarea id="diary-content"></textarea>
```

### label 没有关联输入框

```html
<!-- 不完整 -->
<label>标题</label>
<input id="diary-title">

<!-- 推荐 -->
<label for="diary-title">标题</label>
<input id="diary-title">
```

### 使用 placeholder 代替 label

`placeholder` 在输入后会消失，不能替代明确的 `label`。

## 17. 本课关键字

| 英文 | 中文含义 |
| --- | --- |
| element | 元素，例如完整的 `<p>文字</p>` |
| tag | 标签，例如 `<p>` |
| attribute | 属性，例如 `class="editor"` |
| content | 元素包含的内容 |
| nesting | 把元素放在另一个元素里面 |
| semantic | 使用能表达内容含义的标签 |
| document | 完整 HTML 页面文档 |
| viewport | 浏览器显示页面的区域 |
| form | 收集用户输入的表单 |
| accessibility | 让不同能力的用户都能使用页面 |

完整标签和属性列表见 [HTML 基础语法速查表](HTML基础语法速查表.md)。
