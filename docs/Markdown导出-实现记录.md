# Markdown 导出

单篇阅读页已加入“导出 Markdown”，导出的是当前显示的记录版本，包括尚未上传的本机编辑。导出前明确确认明文风险；文件名使用记录日期和编号，不使用用户标题拼接路径。网页交给浏览器下载；原生端复用系统文件分享适配。

转换器保留标题、基础文字样式、引用、列表、待办、标签和心情。图片未包含时明确标注，不假装已经导出图片；附件路径只允许应用生成的固定目录和图片后缀。下划线使用 HTML u 标签，依赖阅读器的 HTML 支持；有序列表使用数字序号。

尚未完成后台批量 JSON/Markdown+图片 ZIP、日期范围任务、24 小时下载有效期及取消入口。单篇导出不替代完整备份。浏览器下载和原生分享的实际操作验收仍待完成。

## 后台导出推进记录

上述后台待办已有后续实现：新增 004–006 数据库迁移，导出请求去重、账号分页查询、取消、固定版本快照、带租约的归档执行器、私有文件存储、24 小时到期清理及绑定会话的 5 分钟下载链接已接入。真实 HTTP/PostgreSQL 和 ZIP 下载校验累计 48 项接口测试通过。临时记录清理不影响原日记。

`/settings/exports` 已接入日期范围、类型、JSON/Markdown ZIP 选择、请求重试、任务分页、手动刷新、取消和私有下载链接；入口位于同步中心。未确认结果的创建请求在本机保存原请求编号，避免重试换号。237 项单元测试及页面构建通过。

后台 ZIP 现可选择包含图片。执行器从任务冻结的日记正文提取图片编号，只读取同一账号、状态为 ready 的私有原图，按 `assets/<assetId>.webp` 固定路径写入一次；Markdown 使用相对路径引用，缺少任何请求图片会让任务失败，不会生成假装完整的归档。集成测试已实际下载 ZIP、校验图片条目和 Markdown 引用。页面默认勾选“包含已同步图片”，也可关闭以导出纯文字。

后台归档仍有单次 64 MiB 内容限制。浏览器交互、原生 ZIP 下载分享、进程崩溃残留文件清理及生产部署验收仍需补齐。
