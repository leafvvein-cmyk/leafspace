# 保留云端版本：存储层验证

日期：2026-09-08。

存储层实现及验证已完成。冲突页面已接入账号范围内的实时云端读取、正文确认弹窗与明确确认按钮；读取前后和执行前均核对登录状态。页面交互尚未完成实际浏览器验收。

- IndexedDB 和 SQLite 均验证：选择云端后保留本机最新稿备份，读取及草稿入口返回云端内容，旧编辑器保存被拒绝。
- 后续编辑使用所选云端版本作为上传基线；重复处理同一冲突不会覆盖后续编辑。
- 存在结果未确认的上传任务时拒绝处理，保留任务和本机稿。
- 云端版本号增加 PostgreSQL bigint 上限检查。

最新结果：224 项单元测试通过（16 个文件）；既有 41 项真实 HTTP/PostgreSQL 集成测试通过。新增两种存储各两项测试，覆盖云端写入失败的完整事务回滚、较新云端缓存、永久删除和版本号越界。Web 生产构建已在页面接线后通过。未进行浏览器交互或原生设备测试；既有接口回归不等于新增确认弹窗端到端验收。

实时读取和用户明确确认已接线，缓存版本竞态和故障回滚已增加存储测试；后续仍需完整端到端验证。Android SDK、APK、iOS 构建与签名仍未完成。

## 真实接口链路补验

新增 HTTP/PostgreSQL 与 IndexedDB 仿真的联合用例：先上传版本 1，另一客户端通过 PUT 保存版本 2，本机旧基线上传产生真实冲突；重新 GET 云端内容并执行保留后，阻塞任务清除、本机最新稿归档、旧编辑器保存被拒绝；基于云端内容继续编辑成功上传为版本 3。42 项接口集成测试通过。该用例未驱动浏览器弹窗，也不覆盖原生 SQLite 插件和真机网络。

## 快照重建竞态

发现正在下载的旧快照可能在确认之后替换云端镜像。保留云端操作现在与同步状态检查放在同一存储事务中：存在快照请求或暂存快照时停止处理，要求完成同步后重新读取确认。两种存储均覆盖请求已登记、正在下载、已下载但尚未提交三个阶段；旧快照提交后接受新版成功。最新单元测试 226 项通过。同步中心也已区分已处理备份与仅另存副本、原记录仍待处理的状态。
