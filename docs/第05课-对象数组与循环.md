# 第 05 课：对象、数组与循环

## 1. 本课目标

这一课学习三个概念：

1. 对象：把一篇日记的多个字段放在一起。
2. 数组：按顺序保存多篇日记。
3. 循环：逐篇读取数组并生成页面卡片。

```powershell

```

## 2. 为什么一篇日记需要对象

分别建立多个变量会很快失去对应关系：

```js
const title = '散步';
const content = '傍晚沿河走了一圈。';
const createdAt = '2026-09-10 18:30';
```

对象把相关字段组合为一个值：

```js
const entry = {
  id: crypto.randomUUID(),
  title: '散步',
  content: '傍晚沿河走了一圈。',
  createdAt: '2026-09-10 18:30',
};
```

`id`、`title`、`content` 是属性名，冒号后是属性值。最后一项也保留逗号，后续添加字段时更方便。

## 3. 读取与修改对象属性

```js
console.log(entry.title);
entry.title = '晚间散步';
```

点语法适合固定、合法的属性名。方括号可以使用变量：

```js
const fieldName = 'content';
console.log(entry[fieldName]);
```

虽然对象变量用 `const` 声明，仍然可以修改对象内部属性；不能做的是把变量整体指向另一个对象：

```js
entry.title = '新标题'; // 可以
entry = {};             // 不可以
```

## 4. 用函数创建统一对象

```js
function createEntry(title, content) {
  return {
    id: crypto.randomUUID(),
    title,
    content,
    createdAt: new Date().toLocaleString('zh-CN'),
  };
}
```

当属性名与变量名相同，`title` 是 `title: title` 的简写。

`return` 把新对象交给调用位置：

```js
const entry = createEntry('第一篇', '正在学习对象。');
```

每篇记录使用独立 ID，不能把数组位置当长期 ID；排序或删除后位置会变化。

## 5. 数组

```js
const entries = [];
```

`[]` 创建空数组。加入项目：

```js
entries.push(createEntry('第一篇', '学习数组。'));
```

读取数量：

```js
console.log(entries.length);
```

按位置读取：

```js
console.log(entries[0]);
```

数组索引从 0 开始，第一项是 `[0]`。不存在的位置返回 `undefined`。

## 6. 常见数组方法

| 方法 | 作用 | 是否修改原数组 |
| --- | --- | --- |
| `push(value)` | 添加到末尾 | 是 |
| `pop()` | 移除并返回最后一项 | 是 |
| `find(test)` | 找到第一个符合条件的项目 | 否 |
| `filter(test)` | 建立只含符合项目的新数组 | 否 |
| `map(change)` | 把每项转换后建立新数组 | 否 |
| `some(test)` | 是否至少一项符合 | 否 |
| `every(test)` | 是否全部符合 | 否 |

本课先使用 `push` 和循环。后续搜索课再重点练习 `filter`。

清空现有数组而不更换引用：

```js
entries.length = 0;
```

## 7. `for...of` 循环

```js
for (const entry of entries) {
  console.log(entry.title);
}
```

含义是：“依次把数组中的每个项目放进 `entry`，执行花括号里的代码。”

`for...of` 读取数组值；不要用 `for...in` 遍历数组内容，后者读取的是属性名/索引字符串。

需要显示序号时，可以自己维护计数：

```js
let position = 1;
for (const entry of entries) {
  console.log(`第 ${position} 篇：${entry.title}`);
  position = position + 1;
}
```

## 8. 渲染是什么意思

“渲染”是根据当前数据重新生成用户看到的界面。

```js
function renderEntries() {
  entryList.replaceChildren();

  for (const entry of entries) {
    entryList.append(createEntryCard(entry));
  }
}
```

先清空旧卡片，再按当前数组生成卡片。只要所有修改数据的操作之后都调用 `renderEntries()`，页面就能与数组保持一致。

## 9. 安全创建卡片

```js
function createEntryCard(entry) {
  const article = document.createElement('article');
  const heading = document.createElement('h3');
  const content = document.createElement('p');

  heading.textContent = entry.title;
  content.textContent = entry.content;
  article.append(heading, content);
  return article;
}
```

- `createElement()` 创建元素。
- `textContent` 把用户内容当普通文字。
- `append()` 把子元素加入父元素。
- 函数返回完成的卡片。

不要把日记正文直接拼到 `innerHTML` 中。

## 10. 数据属性

```js
article.dataset.entryId = entry.id;
```

浏览器会生成：

```html
<article data-entry-id="..."></article>
```

`data-*` 用于把非敏感的页面标识与元素关联。不要把密码、恢复密钥等秘密放在 DOM 数据属性中。

## 11. 空状态与按钮状态

```js
const count = entries.length;
emptyState.hidden = count > 0;
clearButton.disabled = count === 0;
entryCount.textContent = `${count} 篇`;
```

界面状态来自数组，而不是另外维护多个容易互相矛盾的布尔变量。数组为空时显示解释文字并禁用清空按钮。

## 12. 引用和值

对象和数组通过引用使用：

```js
const first = { title: '原标题' };
const second = first;
second.title = '已修改';
console.log(first.title); // 已修改
```

`first` 与 `second` 指向同一个对象。需要浅复制时：

```js
const copy = { ...first };
```

展开语法只做浅层复制，嵌套对象仍可能共享引用。正式同步代码必须更谨慎处理不可变快照；本课先理解引用概念。

## 13. 作用域

```js
function renderEntries() {
  const count = entries.length;
}

console.log(count); // 报错
```

函数内部声明的 `count` 只在函数内部可用。尽量把变量放在最小需要范围，减少意外修改。

`entries` 位于模块顶层，本文件的函数都可以访问：

```js
const entries = [];
```

模块变量不会自动变成 `window.entries`。

## 14. 调用关系

```text
提交表单
  → saveEntry(event)
  → 读取并验证输入
  → createEntry(title, content)
  → entries.push(newEntry)
  → renderEntries()
      → 清空旧卡片
      → for...of 逐项读取
      → createEntryCard(entry, position)
      → append(card)
      → 更新数量、空状态和按钮状态
```

当列表显示错误时，先检查数组内容，再检查渲染函数，不要直接在页面上手工补一张卡片。

## 15. 常见错误

### 把对象字段写成赋值语句

```js
const entry = { title = '今天' }; // 错误
const entry = { title: '今天' };  // 正确
```

### 数组第一项写成 `[1]`

数组索引从 0 开始。

### 忘记调用渲染函数

数组已经 `push`，页面不会自动变化；修改数据后调用 `renderEntries()`。

### 在循环里使用 `innerHTML +=`

它会反复解析并重建已有 DOM，也可能错误解释用户文字。使用 `createElement`、`textContent` 和 `append`。

### 用数组位置当永久 ID

删除或排序会改变位置。创建记录时生成稳定 ID。

### 修改数组时同时遍历它

循环过程中删除项目可能跳过内容。先确定目标，再在循环外修改，或建立过滤后的新数组。

## 16. 本课关键字

| 关键字 | 含义 |
| --- | --- |
| object | 用属性组合相关数据的对象 |

| array | 按顺序保存多个值的数组 |

## 19. 思考题与参考答案

1. 对象和数组分别解决什么问题？
   - 对象组合一条记录的多个字段；数组保存多条记录并维持顺序。
2. `entries[0]` 表示什么？
   - 数组中的第一项，因为索引从 0 开始。
3. 为什么 `const entries = []` 之后仍能 `push`？
   - const 限制变量不能指向另一个数组，不禁止修改当前数组内容。
4. 为什么每篇日记需要 ID？
   - 标题可能重复，数组位置会变化；稳定 ID 才能可靠识别同一条记录。
5. 为什么统一使用 `renderEntries()`？
   - 它让界面始终从当前数据产生，避免不同操作分别修改 DOM 造成状态不一致。
6. `for...of` 和 `for...in` 有何区别？
   - for...of 读取数组值；for...in 读取对象的可枚举属性名，不适合作为数组内容循环的默认方式。
