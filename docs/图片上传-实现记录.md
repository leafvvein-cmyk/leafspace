# 图片上传实现记录

日期：2026-09-08。

已实现账号空间内的图片上传登记、凭据续签、二进制接收和处理完成接口。上传凭据为短时签名票据，绑定账号、登录会话、资源编号和有效期；退出当前会话后旧票据不能继续上传。资源登记固定真实 MIME、字节数和 SHA-256，同一资源编号不能换成其他文件。

服务端只接受 JPEG、PNG、WebP，单张最多 10 MiB，解码最多 2500 万像素。上传完成后独立校验魔数、声明类型、字节数、摘要和可解码性，重新编码为不保留 EXIF/XMP 的 WebP，并生成最大 320×320 缩略图。源文件在处理成功后从私有暂存区移除，最终文件保存在服务端私有目录；数据库和公开接口只保存/返回资源状态与尺寸，不暴露存储路径。

真实 HTTP/PostgreSQL 测试已覆盖：上传登记与续签去重、账号隔离、文件身份不可替换、实际 PNG 二进制上传、处理后尺寸与状态、完成请求重放、源文件清理、篡改内容拒绝和退出登录后票据失效。当前为 53 项接口集成测试通过；图片处理单元测试覆盖元数据移除、缩略图、伪装格式、摘要和大小错误。

已继续实现私有图片读取：当前账号可为缩略图或原图申请 5 分钟链接，链接绑定账号、登录会话、资源编号、具体派生版本和有效期；请求文件时再次核验会话与数据库状态。其他账号无法申请，篡改链接或退出当前会话后不能读取。响应固定为 `image/webp`、禁止缓存，不暴露服务端存储路径。

新增 `entry_assets` 关联表。日记写入时提取正文中的去重图片编号，并在同一事务中验证全部资源属于当前账号且状态为 ready；未完成或其他账号的资源返回 `ASSET_NOT_READY`，不会只凭资源编号引用图片。日记保存成功后同步更新关联，供后续引用计数、删除和导出使用。

编辑器现已提供选图按钮，只接受 JPEG、PNG、WebP。图片进入日记前会在设备端按 EXIF 方向解码、限制 2500 万像素、最长边缩至 2560 像素、重新编码为 WebP，并计算 SHA-256。网页将字节保存在当前空间的 IndexedDB；原生 App 将字节编码后写入受 SQLCipher 保护的当前空间 SQLite。正文只保存 `assetId`，本机阅读和再次编辑时从私有本机存储生成临时对象地址，不保存 data URL 或外部图片网址。

账号空间的同步协调器会先找出已被日记正文实际引用的本机图片，按“查询远端状态 → 幂等登记 → 签名二进制上传 → 幂等完成”的顺序处理。图片未确认时，文字、标题、心情和标签会先以移除未就绪图片节点后的安全正文同步；图片确认 ready 后，再以已确认文字修订为基础补交完整正文。纯图片空白记录会等待，避免云端出现无意义空日记。完成响应丢失时先查询远端状态修复本机确认，未被正文引用的临时图片不会自动上传。

每次上传失败都会在当前账号空间记录安全错误码和通用提示，不持久化原始服务端消息、签名票据或请求头。连续失败 3 次后停止自动重试，并在“设置 → 图片问题”列出相关日记和手动重试按钮；重新排队不会丢弃本机原图。编辑器分别显示“日记已保存”和图片等待/失败状态，不用文字保存成功冒充整篇已同步。

另一台设备读取含图片的云端日记时，会先获取当前账号与会话绑定的短时原图链接，限定同源接口路径、`image/webp` 和 10 MiB，再下载、重新计算摘要并写入当前设备的私有图片存储。并发读取同一图片会共用一次下载；退出或切换账号时旧链接仍由服务端会话复核拒绝。

“设置 → 存储空间”区分不可自动恢复的本机原件与可重新下载的云端缓存。清理操作只删除标记为远端下载且已就绪的缓存；待上传、上传失败和学习空间本机原图都受保护。浏览器端测试会同时放置两类相同大小图片，确认清理后只有云端缓存消失。

图片关联现在记录 `orphaned_at`：有任意日记引用时清空该时间，最后一篇日记移除引用时重新开始计时。后台清理器只认数据库实际引用，孤立满 7 天后先把资源原子标记为 deleted，再删除源文件、原图和缩略图；若进程在两步之间退出，下次会继续清理遗留文件。回收站日记仍保留关联，不会提前删除图片。

含图云端导出会读取任务冻结正文实际引用的同账号 ready 原图，以固定 `assets/<assetId>.webp` 路径写入 ZIP，并让 Markdown 使用相对路径。任何请求图片缺失都会使任务失败，不生成缺图却声称完整的归档。

当前统一回归包含 295 项单元/仓储测试和 60 项真实 HTTP/PostgreSQL 集成测试。集成测试实际制造终止性上传失败，确认文字先形成云端修订，再手动重试并上传真实 PNG，最终以第二个云端修订建立 `entry_assets` 关联。桌面与手机布局另有失败页、手动重试、拖图、状态提示和安全缓存清理测试。Android/iOS 真机权限、厂商图片格式、相机方向、低内存、系统分享和多设备恢复仍未验收；不能把浏览器测试、资源同步或构建通过视为手机安装包交付。
