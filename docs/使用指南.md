# 日记本使用指南

## 1. 打开页面

- 电脑网页版：<http://127.0.0.1:4173/today>
- 手机布局预览：<http://127.0.0.1:4174/today>

手机布局预览需要使用窄窗口（建议约 390 像素宽）。它用于检查响应式页面，不等于 Android/iOS 真机 App；相机、通知、生物识别、安全存储和 App 唤起仍需安装包与真机验证。

## 2. 注册与登录

1. 点击“注册账号”。
2. 账号使用 3–32 位字母、数字、`.`、`_` 或 `-`，首位必须是字母或数字。
3. 密码使用 12–128 个字符，并再次输入确认。
4. 注册后按提示保存恢复码。恢复码只在明确生成时显示，不能替代密码本恢复密钥。

登录只需要账号和密码，不使用手机验证码、Apple 登录或其他第三方登录。未登录时可以使用学习空间；学习空间数据只属于当前浏览器，需要在设置中明确预览并复制到账号空间。

## 3. 日记功能

- “今天”：每天一篇正式日记，可填写标题、正文、心情、标签和图片。
- “随记”：同一天可以记录多条临时想法。
- “时间线”：按时间浏览，并按类型、心情、标签和日期筛选。
- “日历”：查看每日记录和心情分布，点击日期进入当天内容。
- “搜索”：输入文字后搜索名称、正文和标签。
- “回收站”：恢复误删内容；永久删除前需再次确认。

内容先保存到本机。登录账号后，同步状态应以“已确认”“待上传”“冲突”或“同步失败”等实际提示为准，不能仅凭登录成功判断全部数据已经上传。

## 4. 待办功能

1. 进入“待办”，点击“新建待办”。
2. 填写标题，可选填写备注、截止时间、优先级和提醒时间。
3. 可添加子项，或设置按日、按指定星期、按月重复。
4. 完成重复待办后，系统生成下一次实例。
5. 快捷动作必须经过确认后才执行，执行动作不会自动把待办标为完成。

站内页面和 HTTPS 动作可以使用。企业微信及其他原生 App 动作必须先登记产品白名单、安装 App Launcher，并在 Android/iOS 真机上验证；当前不显示任意 scheme、包名或命令输入入口。

## 5. 密码本

1. 第一次进入“密码本”时创建独立保险库密码，至少 12 个字符。
2. 保存一次性显示的 256 位恢复密钥，并与保险库密码、加密备份分开保管。
3. 点击“添加账号”，选择 App 账号或网站账号。
4. 填写服务名称、账号、密码；可选填写网址/App 标识、标签、备注和 Base32 TOTP 动态验证码密钥。
5. 列表中可复制账号、复制密码、临时显示密码或动态验证码。
6. 切到后台或闲置 5 分钟后，密码本自动锁定。
7. 定期选择“导出加密备份”。普通日记备份不会包含密码本。

账号空间还提供“轮换数据密钥”。这是高级安全操作：先完成密码本同步，输入当前保险库密码，保存页面一次性显示的新恢复密钥，再勾选确认并开始轮换。确认前可以取消且不会更换密钥；确认后保险库会锁定并由同步队列完成全部密文切换。网络中断时不要重复创建另一轮任务，恢复网络后进入“同步”继续原任务。完成后旧恢复密钥失效，应立即更新离线保存的恢复资料。

密码本只在客户端解密，服务端保存密文。当前版本仍需原生真机上的 WebAssembly、安全存储、SQLCipher、后台遮挡和剪贴板行为验收，因此不要把它当作凭据的唯一副本。

## 6. 设置与安全

- “同步”：查看待上传、失败、冲突及云端检查状态。
- “外观”：选择主题、阅读字体、字号和电脑书写宽度。
- “日记锁”：设置本机 PIN；支持条件满足时的原生生物识别。
- “提醒”：设置每台设备自己的提醒时间和星期。
- “设备”：查看账号会话，并在重新验证密码后撤销其他设备。
- “导出”：保留日记备份；密码本必须使用密码本页面中的独立加密备份。

## 7. 自己启动

首次或数据库停止后：

```powershell
npm run db:up
npm run db:migrate
```

分别打开终端运行：

```powershell
npm run dev:api
npm run build
npm run preview
```

手机布局预览：

```powershell
npm run build:mobile
npm run preview:mobile
```

若端口被占用，应先确认占用进程属于本项目，不要直接终止未知程序。
