安全执行顺序

  1. npm run mobile:doctor：只读检查环境。
  2. npm run mobile:sync：构建网页并复制到 Android/iOS。
  3. npm run mobile:android：环境完整后尝试 Android 调试包。
  4. 在 Mac 上执行 npm run open:ios --workspace @diary/mobile 并由 Xcode 构建。
  5. 最后必须真机安装并逐项验收权限、离线、同步和安全存储。
为什么手机预览不等于手机 App？

http://127.0.0.1:4174 只预览移动构建的网页布局。只有 Capacitor 把资源复制进原生工程并由 Android/iOS 工具链编译后，才可能得到安装包；得到安装包后仍要真机验收。
